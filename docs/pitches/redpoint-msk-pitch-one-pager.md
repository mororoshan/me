# RedPoint — Pitch One-Pager

**Для встречи с ООО «Ред Поинт»**

## Диагноз за 30 секунд

Сайт http://redpoint.msk.ru/ не продаёт скалодром. Он работает как архив новостей 2018–2020 на устаревшем desktop-шаблоне (сетка 960px, без mobile viewport) на EOL-стеке (Apache 2.2 / PHP 5.3). При этом у клуба сильный продукт: арка 12,5 м (уникальная в Москве), эталон скорости 10 м, боулдер-зал, детская и взрослая школы, праздники.

## Что теряют

- Новички не видят путь «первый визит → вводное → запись»
- Цены — таблица для кассира, не для гостя
- Телефон/SMS — единственный канал; заявки не измеряются
- Бренд выглядит слабее, чем залы

## Предложение

**Фаза 1 — маркетинговый сайт:** современный mobile-first сайт, сильный hero с реальной аркой, упрощённые цены + полный прайс, страницы новичкам/детям/праздникам, формы заявок в Telegram/почту, HTTPS, редиректы со старых URL, Метрика.

**Фаза 2 — рост:** запись на вводные / персоналки / праздники.

## Результат для клуба

Больше вводных и детских лидов, меньше однотипных звонков, сайт как витрина уникальных стен, безопасный хостинг.
